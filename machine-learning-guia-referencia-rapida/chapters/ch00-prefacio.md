# Prefácio

## Nota
Front matter do livro (motivação do autor, público-alvo, convenções tipográficas, agradecimentos) — sem conteúdo técnico de ML. Reproduzido de forma sucinta por completude do índice.

## Core Idea
O livro é deliberadamente uma referência de bolso ("pocket reference") para machine learning com **dados estruturados**, não um curso — assume conhecimento prévio de Python, deixa deep learning de fora por escolha editorial (recomendando XGBoost e afins para dados estruturados, deep learning só para dados não estruturados como imagem/áudio/vídeo), e é usado pelo próprio autor como material de apoio em seus cursos de análise de dados e ML.

## Key Concepts
- **Público-alvo**: iniciantes e praticantes experientes de ML, desde que já tenham familiaridade com Python (a sintaxe da linguagem não é ensinada).
- **Escopo deliberado**: dados estruturados, não deep learning — decisão editorial explícita, não lacuna acidental.
- **Convenções tipográficas**: itálico para termos novos/URLs/nomes de arquivo; largura constante para código/variáveis/comandos; blocos **DICA**/**NOTA**/**ALERTA** para sugestão, observação geral e aviso, respectivamente (convenção seguida em todos os capítulos técnicos).
- **Título original**: *Machine Learning Pocket Reference*, Matt Harrison (O'Reilly, 2019, ISBN 978-1-492-04754-4) — esta edição é a tradução brasileira publicada pela Novatec.
- **Repositório de material suplementar do autor**: https://github.com/mattharrison/ml_pocket_reference (exemplos de código, exercícios).
