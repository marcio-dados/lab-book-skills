# Capítulo 2: Visão geral do processo de machine learning

## Core Idea
O CRISP-DM (Cross-Industry Standard Process for Data Mining) — entendimento do negócio, entendimento dos dados, preparação dos dados, modelagem, avaliação, implantação — é o esqueleto do fluxo de trabalho do livro; os capítulos seguintes expandem cada um desses passos em detalhe prático.

## Key Concepts
- **CRISP-DM**: processo iterativo de 6 etapas (negócio → dados → preparação → modelagem → avaliação → implantação) usado como referência de mercado para mineração de dados.
- O fluxo do autor expande o CRISP-DM em passos mais granulares e concretos — cobertos capítulo a capítulo no restante do livro (limpeza, criação de atributos, separação de amostras, imputação, modelo de base, avaliação, otimização, implantação).

## Mental Models
- Pense no CRISP-DM não como um checklist linear e único, mas como um ciclo de melhoria contínua — voltar a etapas anteriores (ex. preparação de dados) conforme a avaliação do modelo revela novas necessidades é esperado, não uma falha do processo.

## Key Takeaways
1. Todo o restante do livro é uma expansão prática das 6 etapas do CRISP-DM.
2. A ordem apresentada (negócio → dados → preparação → modelagem → avaliação → implantação) é a estrutura organizacional dos capítulos 3 a 19.
